修改：

csharp
public void StockOut(int quantity)
{
    if (quantity <= 0)
        throw new ArgumentException("出库数量必须大于 0", nameof(quantity));
    if (quantity > Quantity)
        throw new BusinessException("出库数量不能超过当前库存");

    Quantity -= quantity;
    Status = Quantity > 0 ? ItemStatus.InStock : ItemStatus.OutStock;
    UpdatedAt = DateTime.UtcNow;
}

P1-10 UnitOfWork 事务对象未保存
文件：UnitOfWork.cs
问题：BeginTransactionAsync / CommitAsync / RollbackAsync 没保存 IDbContextTransaction 对象，嵌套调用会抛异常。
修改：

csharp
private IDbContextTransaction? _transaction;

public async Task BeginTransactionAsync()
{
    if (_transaction != null) return;
    _transaction = await _context.Database.BeginTransactionAsync();
}

public async Task CommitAsync()
{
    if (_transaction == null) return;
    await _transaction.CommitAsync();
    await _transaction.DisposeAsync();
    _transaction = null;
}

public async Task RollbackAsync()
{
    if (_transaction == null) return;
    await _transaction.RollbackAsync();
    await _transaction.DisposeAsync();
    _transaction = null;
}
并加 using Microsoft.EntityFrameworkCore.Storage;。

P2 级：安全 / 权限问题（你这套系统最大的一块）
P2-1 数据范围过滤完全没做
涉及：所有 Service 的 GetAll / GetById 查询。
问题：RoleCategory、RoleLocation 建了，但没有任何查询用它过滤。任何登录用户能看到全表。
修改方向：

在 Application 层定义 ICurrentUserService 接口：

csharp
public interface ICurrentUserService
{
    int UserId { get; }
    int RoleId { get; }
    bool IsAdmin { get; }
    IReadOnlyCollection<string> Permissions { get; }
}
在 Infrastructure 实现，通过 IHttpContextAccessor 从 JWT Claims 读。

Repository 加数据范围参数：

csharp

    IReadOnlyCollection<int>? allowedCategoryIds,
    IReadOnlyCollection<int>? allowedLocationIds,
    int? categoryId,
    int? locationId);
Service 里：

csharp

    ? null
    : await _unitOfWork.Roles.GetAllowedCategoryIdsAsync(currentUser.RoleId);
var items = await _unitOfWork.Items.SearchAsync(allowedCategories, ...);
P2-2 操作权限完全没做
涉及：ItemsController、CategoriesController、LocationsController、UsersController
问题：Create / Update / Delete 只用 [Authorize] 或直接没有，任何登录用户都能改。
修改方向：

定义权限常量：

csharp
public static class PermissionCodes
{
    public const string ItemCreate = "item.create";
    public const string ItemUpdate = "item.update";
    public const string ItemDelete = "item.delete";
    public const string CategoryCreate = "category.create";
    // ...
}
实现 PermissionAuthorizationHandler，读 JWT 里的 Permission Claims。

Controller 用 Policy：

csharp
[Authorize(Policy = PermissionCodes.ItemCreate)]
public async Task<ActionResult<ItemResponseDto>> Create(...)
